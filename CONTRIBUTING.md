# Contributing

Obrigado pelo interesse em contribuir!

## Como contribuir

1. Faz fork do repo
2. Cria um branch (`git checkout -b feature/nova-config`)
3. Commit (`git commit -m 'feat: adiciona nova config'`)
4. Push (`git push origin feature/nova-config`)
5. Abre um Pull Request

## Guidelines

- Mantém as configs organizadas por ferramenta
- Adiciona comentários explicativos
- Usa caminhos relativos (`$HOME` em vez de caminhos absolutos)
- Testa antes de submeter

## Licença

Ao contribuir, aceitas que o teu trabalho será licenciado sob MIT.
