# Código de Conduta

## O nosso compromisso

Este projecto é mantido num ambiente aberto e respeitoso. Todos os contribuidores devem:

- Ser respeitosos com opiniões e experiências diferentes
- Aceitar críticas construtivas
- Focar no que é melhor para a comunidade
- Mostrar empatia para com outros membros

## Comportamento inaceitável

- Linguagem ou imagens sexuais
- Trolling, insultos, ataques pessoais
- Assédio público ou privado
- Publicar informação privada sem consentimento
